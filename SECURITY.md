# Política de Segurança

## Versões suportadas

A versão mais recente é a única mantida ativamente.

| Versão | Suporte |
| --- | --- |
| 1.2.x mais recente | ✅ |
| versões anteriores | ❌ |

## Relato de vulnerabilidades

Não abra uma issue pública contendo:

- mensagens privadas;
- números de telefone;
- e-mails;
- tokens, cookies ou dados de sessão;
- capturas de tela com informações pessoais;
- qualquer credencial.

Ao relatar uma vulnerabilidade, forneça apenas o mínimo necessário para reprodução e remova dados pessoais.

## Princípios do projeto

- menor privilégio possível dentro das necessidades funcionais;
- nenhum backend próprio para armazenar mensagens;
- configurações em armazenamento local da extensão;
- não executar código remoto;
- não incluir analytics ou telemetria externa sem documentação explícita.
